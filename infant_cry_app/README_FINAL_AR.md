# Pediatric Cry Care — النسخة المعدلة

هذه النسخة مبنية على ملف `infant_cry_app.zip` الذي تم اعتماده كنسخة الأساس. تم الحفاظ على تصميم المشروع وإضافة وظائف الواجهة والمنطق المطلوبة.

## التعديلات الموجودة

تمت إضافة صفحة مستقلة لإنشاء حساب الأم، مع الاسم الكامل والبريد وكلمة المرور وصورة شخصية اختيارية. يتم حفظ الصورة والاسم في ملف المستخدم داخل Firestore، ولا تظهر اختيارات الصورة في شاشة تسجيل الدخول للحسابات الموجودة.

تمت إضافة زر إظهار وإخفاء كلمة المرور في تسجيل الدخول وتسجيل الدكتور وتسجيل الأم، كما يمكن الضغط على Enter لتنفيذ الدخول أو إنشاء الحساب.

تم تعديل الشات ليحدد تلقائياً هل الحساب أم أم دكتور اعتماداً على حساب Firebase الحالي. أُلغي اختيار الدور اليدوي، وتُحفظ الرسائل الجديدة باسم المرسل الكامل الموجود في حساب الأم أو الدكتور.

تمت إضافة حفظ صورة الدكتور وملف الشهادة أثناء طلب التسجيل. تعرض لوحة الإدارة بيانات الطلب كاملة، ويمكن فتح ملف الشهادة المرفوع من نافذة التفاصيل إذا كان الملف محفوظاً كرابط بيانات.

## التشغيل على Windows وChrome

افتح مجلد `infant_cry_app` الداخلي في VS Code، وليس المجلد الأب. ثم افتح Terminal داخل نفس المجلد ونفّذ الأوامر التالية:

```powershell
flutter clean
flutter pub get
flutter run -d chrome
```

إذا ظهرت رسالة تفيد بوجود إصدارات أحدث من بعض الحزم مع بقاء `Got dependencies`، فهي تحذير وليست سبب فشل التشغيل. أما إذا ظهر خطأ Firebase أو صلاحيات Firestore، فيجب مراجعة إعدادات Firebase Rules والحسابات الموجودة في المشروع.

> هذه التعديلات Front-End/Logic داخل `lib/main.dart`، وتحتاج إلى إعداد Firebase الصحيح الخاص بالمشروع حتى تعمل المصادقة وFirestore بصورة كاملة.
